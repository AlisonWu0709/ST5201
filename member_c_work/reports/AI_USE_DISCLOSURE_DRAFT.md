# AI-use disclosure draft

Generative AI tools were used to assist with code scaffolding, debugging, command-line guidance, test design, result-audit scripts and English-language editing. AI-generated suggestions were not accepted solely on authority. We checked the implementation against the assignment specification, preserved run provenance, ran automated tests, verified method interfaces, and independently recomputed means, sample standard deviations and Monte Carlo standard errors from repetition-level results. We also checked dataset pairing, formal-run identity, numerical summaries and representative figures. Group members reviewed the final statistical interpretations and remain responsible for understanding the methods, verifying the results and acknowledging the supplied MF implementation and other sources.
