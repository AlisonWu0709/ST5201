# Submission checklist

- [ ] Main PDF is at most 10 pages, excluding title page and references.
- [ ] Optional appendix is at most 3 pages; the main argument is self-contained.
- [ ] Final reflection is at most 200 words.
- [ ] Every table and figure is cited and has an informative caption.
- [ ] Oracle and fitted methods are labelled explicitly.
- [ ] MCSE is based on 50 repetition-level results.
- [ ] Part D states question, target and conjecture before results.
- [ ] Part D varies `b` and `n`, reports uncertainty and one limitation, and ends with a concise answer.
- [ ] Code, README and numerical summaries underlying main figures are included in one archive.
- [ ] README states software versions and reproduction commands and separates generation, fitting and evaluation.
- [ ] Archive excludes `.venv`, caches, temporary logs, smoke/demo artefacts and unnecessary large checkpoints.
- [ ] Contribution statement contains verified names and responsibilities.
- [ ] AI-use disclosure is included and describes how substantial assistance was checked.
- [ ] All placeholders are replaced.
- [ ] Final tests, `git diff --check` and `git status` have been reviewed.
- [ ] Team has reviewed the final branch/PR and resolved conflicts without overwriting work.
- [ ] Email `zhigang.yao@nus.edu.sg` with all group-member names before submission.
- [ ] Confirm that the Canvas submission folder has been created.
